# Баланс — веб-прототип (фин-консультация)

Рабочее название. Продукт — **разбор финансового состояния + советник**, не трекер.

## Файлы
- `index.html` — лендинг.
- `app.html` — приложение (разбор + советник + динамика + профиль). Загружает логику из `js/` через `<script type="module">`.
- `js/` — модули ES:
  - `parser.js` — разбор CSV-выписки (чистый).
  - `categories.js` — категоризация операций (чистый).
  - `analyzer.js` — ядро разбора: агрегаты, score, риски, рекомендации (чистый).
  - `advisor.js` — правило-основанный советник, отвечает по данным + сравнение с историей (чистый).
  - `store.js` — снимки разборов и профиль в localStorage (единственный модуль, трогающий хранилище).
  - `dynamics.js` — расчёт динамики по снимкам (чистый).
  - `demo.js` — демо-данные (чистый).
  - `ui.js` — рендер экранов (единственный модуль, трогающий DOM).

Чистые модули не зависят от DOM/localStorage/сети — их можно перенести на бэкенд без переписывания.

## Запуск
Любой статический сервер, открыть `app.html`. В этом проекте: `node .claude/serve.js` (порт 4599) → `http://localhost:4599/prototype/app.html`.

## Тесты ядра
```
node --test "prototype/tests/**/*.test.js"
```
Юнит-тесты чистых модулей (parser, categories, analyzer, advisor, store, dynamics). UI проверяется вручную в браузере.

## Границы
Бытовые финансы + образовательный ликбез про накопления. Без персональных инвестиционных рекомендаций. Данные не покидают браузер.
